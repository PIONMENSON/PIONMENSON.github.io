# Hyojun Yun — academic homepage

Personal research homepage: https://pionmenson.github.io/

Static HTML and CSS, published with GitHub Pages from the root of `main`.
Edit `index.html` for biography, education, publications, projects, and study links.
Edit `style.css` for layout and typography. No build step or JavaScript is required.

The visual structure references [Youngjin Seo](https://gomtaeng2.github.io/) and [Jon Barron](https://jonbarron.info/). The implementation and personal copy were written for this site.

Lato fonts are distributed under the SIL Open Font License; see `assets/Lato-OFL.txt`.
Publication figures illustrate Hyojun Yun's co-authored work. The NPU benchmark figure is also shown on Youngjin Seo's homepage.
